1. What does the client get if it sends an invalid message to the web service?

In case of an error, the response is a SOAP fault, and its faultcode and faultstring elements describe the error. See the Error handling section.

2. Which element of the SOAP envelope contains the HelloRequest element?

The content of the message goes into the Body element inside the Envelope element. See the Request and response section.

3. Which part of the WSDL document contains the address of the web service?

The port inside the service element contains the address, in the location attribute of the soap:address element. See the WSDL section.
